ez_grav CLI, TUI & Devcontainer Reference Manual

The ez_grav engine provides a command-line interface, an interactive terminal user interface, and devcontainer tooling for Python's antigravity ecosystem. This reference manual consolidates all runtime options, command palette syntax, hotkey shortcuts, telemetry specs, physics equations, devcontainer specs, and GitHub CLI workflows into structured, scannable tables.

5. Core Mathematical & Physics Equations

ez_grav calculates telemetry using these foundational equations:

Physics Metric

Equation

Variable Definitions

Net Lift Force

$F_{\text{net}} = m \cdot g_0 \cdot \left(1 + \frac{h}{1000} \cdot 0.01\right) - m \cdot g_0$

$m$: mass ($\text{kg}$), $g_0 = 9.80665\text{ m/s}^2$, $h$: altitude ($\text{m}$)

Orbital Velocity

$v = \sqrt{\frac{G \cdot M_{\oplus}}{R_{\oplus} + h_{\text{orbit}}}}$

$G = 6.6743 \times 10^{-11}\text{ m}^3\text{kg}^{-1}\text{s}^{-2}$, $M_{\oplus} = 5.972 \times 10^{24}\text{ kg}$, $R_{\oplus} = 6.371 \times 10^6\text{ m}$

Thermal Cooling

$\frac{dT_{\text{coil}}}{dt} = -k \cdot (T_{\text{coil}} - T_{\text{ambient}})$

$k$: cooling rate constant ($0.5\text{ s}^{-1}$), $T_{\text{ambient}} = 20.0^\circ\text{C}$

8. Python API Integration Quickstart

The core GravEngine class can also be integrated directly into external Python tools:

import ez_grav

# 1. Instantiate the core engine
engine = ez_grav.GravEngine(mass_kg=85.0, zero_g=True, verbose=True)

# 2. Configure antigravity settings
engine.enable_zero_g(True)
engine.mass_swap()  # Flips mass tensor to negative mass mode

# 3. Retrieve telemetry calculations
lift = engine.get_lift_force()
v_orb = engine.calculate_orbital_velocity(altitude_km=400.0)

print(f"Net Lift Force    : {lift} N")
print(f"LEO Orbital Speed : {v_orb} m/s")
